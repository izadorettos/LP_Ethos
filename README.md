# 🏛️ Ethos Leadership - Landing Page Institucional Responsiva

Uma landing page elegante e sofisticada para mentorias de liderança, desenvolvida com o objetivo de aplicar conceitos avançados de **Design "Quiet Luxury"**, **Semântica HTML** e **UX (Experiência do Utilizador)**.

## 🚀 Demonstração
O projeto está disponível online para visualização:
👉 [Link de demonstração](ethos.symgente.com.br)

---

## 📋 Sobre o Projeto
Este site foi criado para transmitir autoridade e virtude no contexto de liderança empresarial e pessoal. A interface utiliza uma estética minimalista e premium para atrair executivos e líderes que buscam transformação real.

### Funcionalidades:
- **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
- **Micro-interações:** Animações suaves de scroll e efeitos de hover de alta fidelidade.
- **Método SYM:** Seção interativa com sistema de expansão para detalhamento dos pilares da liderança.
- **Social Proof Dinâmico:** Carrosséis infinitos para exibição de parceiros e frases de impacto.

---

## 🛠 Tecnologias Utilizadas
As seguintes ferramentas foram usadas na construção do projeto:
* **HTML5:** Estrutura semântica para melhor SEO e acessibilidade.
* **CSS3:** Estilização com variáveis personalizadas, Flexbox e CSS Grid para um layout moderno e responsivo.
* **JavaScript:** Lógica de interação para menu mobile, accordions e controle de animações.

---

## 📂 Estrutura de Pastas
Para garantir a organização do código, utilizei a seguinte estrutura:
- `/assets`: Contendo subpastas para logotipos e imagens otimizadas em WebP.
- `index.html`: Página principal contendo a estrutura e os estilos embutidos.
